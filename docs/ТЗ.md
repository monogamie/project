# Техническое задание

## Название проекта

«Домашняя библиотека»: настольное приложение для учёта книг.

## Назначение

Программа хранит список книг, которые есть дома или которые пользователь хочет прочитать. Для каждой книги можно указать автора, жанр, год, число страниц, оценку, статус и обложку. Пользователь отмечает, сколько страниц прочитал в какой день, и смотрит статистику за год.

## Функции

1. Добавление, изменение и удаление книг.
2. Справочники авторов и жанров с добавлением, правкой и удалением записей.
3. Поиск по названию и автору, фильтр по жанру, статусу и любимым книгам, сортировка по любому столбцу.
4. Журнал чтения: дата и число прочитанных страниц, прогресс по книге. Когда прочитаны все страницы, программа предлагает поставить статус «Прочитано».
5. Календарь, в котором подсвечены дни чтения.
6. Статистика: счётчики книг, цель на год в страницах, диаграммы по жанрам и по месяцам.
7. Импорт и экспорт списка книг в CSV, сохранение отчёта в TXT.
8. Выбор шрифта таблицы и цвета оформления, настройки сохраняются в базе.
9. При первом запуске база заполняется примерами из CSV.

## Требования к реализации

- Язык Python 3, библиотека PyQt5, база данных SQLite.
- Зависимости перечислены в requirements.txt.
- Несколько форм: главное окно, карточка книги, журнал чтения, справочник авторов, форма автора, справочник жанров, «О программе».
- Стандартные диалоги: QFileDialog, QMessageBox, QInputDialog, QFontDialog, QColorDialog.
- В базе не меньше трёх связанных таблиц; чтение, добавление, изменение и удаление данных.
- Программа собирается в один исполняемый файл с помощью PyInstaller.
