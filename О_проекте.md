# Домашняя библиотека (PyQt6)

Настольное приложение для учёта домашней библиотеки: книги, авторы, жанры, журнал чтения, статистика.

## Запуск

```
pip install -r requirements.txt
python main.py
```

При первом запуске рядом с программой создаётся база `library.db` и заполняется примерами из `data/books_sample.csv`.

## Сборка exe

Запустите `Собрать_exe.bat`. Готовый файл появится в `dist\LibraryApp.exe`.
Картинки и CSV упаковываются внутрь exe, база `library.db` и папка `covers` создаются рядом с ним.

## Что лежит в папке

| Что | Зачем |
|---|---|
| `main.py` | запуск программы |
| `requirements.txt` | список библиотек (PyQt6, PyInstaller) |
| `Собрать_exe.bat` | сборка программы в один exe-файл |
| `app/` | код программы: база данных, главное окно, остальные окна, свои виджеты |
| `data/` | примеры книг (CSV) и цитаты (TXT) |
| `images/` | логотип, заставка, иконки |
| `tools/make_images.py` | скрипт, которым нарисованы картинки из `images/` |
| `dist/LibraryApp.exe` | готовая программа |
| `Документы/` | техническое задание, пояснительная записка, презентация |

## Соответствие требованиям

| Требование | Где |
|---|---|
| requirements.txt | `requirements.txt` |
| Несколько форм | главное окно, книга, журнал чтения, авторы, автор, жанры, «О программе» |
| Изученные виджеты | кнопки, поля ввода, списки, таблицы, флажки, переключатели, ползунок, вкладки, прогресс-бар и др. |
| Дополнительные виджеты | QCalendarWidget, QDateEdit, QDial, QLCDNumber, QSplitter, QSplashScreen, свои виджеты на QPainter |
| Стандартные диалоги | QFileDialog, QMessageBox, QInputDialog, QFontDialog, QColorDialog |
| Картинки | `images/` (логотип, заставка, иконки), обложки книг |
| txt / csv | `data/quotes.txt`, `data/books_sample.csv`, импорт и экспорт CSV, отчёт TXT |
| Несколько таблиц в БД | genres, authors, books, readings, settings |
| Чтение / запись / изменение | `app/database.py` |
| exe | `Собрать_exe.bat` (PyInstaller, `--onefile`) |
