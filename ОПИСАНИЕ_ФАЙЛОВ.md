# Зачем нужен каждый файл

Здесь перечислены все файлы проекта. Для каждого написано, что в нём и что сломается, если его удалить.

## Корень проекта

| Файл | Зачем нужен |
|---|---|
| `main.py` | Точка входа: с него запускается программа (`python main.py`). Создаёт приложение, включает русский язык, показывает заставку, открывает базу (при первом запуске заполняет её примерами) и открывает главное окно. Без него программа не запустится. |
| `requirements.txt` | Список библиотек, нужных проекту: PyQt6 (окна и кнопки) и PyInstaller (сборка exe). Ставятся одной командой `pip install -r requirements.txt`. Отдельный пункт требований к проекту. |
| `build_exe.bat` | Сборка exe на Windows. Запускаешь двойным кликом, через 1-3 минуты в папке `dist` появляется `LibraryApp.exe`. Внутри одна команда PyInstaller со всеми настройками: один файл, без консоли, с иконкой, с картинками и данными внутри. |
| `build_exe.sh` | То же самое для Linux и macOS. На Windows не нужен, но и не мешает. |
| `README.md` | Короткая справка: как запустить, как собрать exe, таблица соответствия требованиям. Это первое, что открывают, когда смотрят чужой проект. |
| `ОПИСАНИЕ_ФАЙЛОВ.md` | Этот файл. |

## Папка `app/`: весь код программы

| Файл | Зачем нужен |
|---|---|
| `__init__.py` | Почти пустой файл. Он говорит Python, что `app` это пакет, поэтому в `main.py` работает `from app.database import Database`. |
| `paths.py` | Отвечает за пути к файлам. При запуске через `python` картинки лежат рядом, а в exe они распакованы во временную папку `sys._MEIPASS`. Этот файл находит их в обоих случаях. Он же решает, где хранить базу и обложки: рядом с exe, чтобы данные не пропадали. |
| `database.py` | Вся работа с базой данных SQLite. Создание 5 таблиц, все запросы SELECT, INSERT, UPDATE, DELETE, статистика, импорт и экспорт CSV. Остальные файлы сами SQL не пишут, только вызывают методы отсюда. |
| `main_window.py` | Главное окно: меню, панель инструментов, фильтры слева, таблица книг, вкладки «Статистика» и «Календарь чтения», карточка книги справа. Здесь обработчики почти всех кнопок: добавить, изменить, удалить, импорт, экспорт, отчёт, выбор шрифта и цвета. |
| `book_dialog.py` | Окно «Новая книга» / «Редактирование книги»: поля, выбор обложки, проверка и сохранение в базу. |
| `author_dialog.py` | Три окна: форма одного автора, справочник авторов (таблица с правкой прямо в ячейках) и справочник жанров (список с добавлением, переименованием, удалением). |
| `reading_dialog.py` | Окно «Журнал чтения»: в какой день сколько страниц прочитано, прогресс по книге, автоматическая смена статуса. |
| `stats_widget.py` | Вкладка «Статистика»: цифровые счётчики, цель на год, две диаграммы. |
| `widgets.py` | Самодельные виджеты: обложка книги с заглушкой, звёзды рейтинга, столбчатая диаграмма. Звёзды и диаграмма нарисованы вручную через QPainter. |
| `about_dialog.py` | Окно «О программе» с логотипом. |

## Папка `data/`: данные в файлах

| Файл | Зачем нужен |
|---|---|
| `books_sample.csv` | 16 книг-примеров. При первом запуске база пустая, и программа заполняет её из этого файла, чтобы сразу было что показать. Ещё это пример формата для импорта CSV. Закрывает требование «файлы csv». |
| `quotes.txt` | Цитаты о книгах, по одной на строку. Программа берёт случайную и показывает в блоке «Цитата дня». Закрывает требование «файлы txt». |

## Папка `tools/`

| Файл | Зачем нужен |
|---|---|
| `make_images.py` | Скрипт, которым нарисованы все картинки из `images/` (через QPainter, кодом). Программа его не запускает, он нужен, только если захочешь перерисовать картинки. Если спросят «откуда картинки», ответ здесь. |

| Файл | Зачем нужен |
|---|---|

## Файлы, которые появятся сами (их нет в архиве, и это нормально)

| Что | Откуда берётся |
|---|---|
| `library.db` | База данных. Создаётся при первом запуске рядом с `main.py` или рядом с exe. Удалишь, и при следующем запуске создастся заново с 16 примерами. |
| `covers/` | Папка с обложками, которые ты выбрал для книг. Появляется, когда первый раз выбираешь обложку. |
| `__pycache__/` | Служебная папка Python с ускоренными копиями кода. Создаётся сама, можно удалять. |
| `build/` и `LibraryApp.spec` | Временные файлы PyInstaller после сборки. Можно удалить. |
| `dist/LibraryApp.exe` | Готовый exe после запуска `build_exe.bat`. **Его положи в архив перед сдачей.** |
